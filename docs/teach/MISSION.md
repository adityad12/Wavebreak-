# Mission: Building LLM apps in Python

## Why
Build Wavebreak, an open-source AI Companion that supports people through urges, and learn Python and its libraries by doing it. The user needs to understand each part of the code well enough to change it and explain it, not just run it.

## Success looks like
- Explain how a chat app gives an LLM memory, and point to the lines of Wavebreak that do it.
- Change the history limits and the crisis-check context without breaking the tests.
- Decide for themselves between options such as stateless and stored history, and write down why.

## Constraints
- Learning happens alongside building, in short sessions.
- Python is the main language. The user is newer to it and to LLM tooling.
- Free tools only for now (Gemini free tier, made-up conversations only).

## Out of scope
- Fine-tuning models.
- The native mobile app.
