# Rationale

The detailed "why" behind each file in `../decisions/`, using the same filename. Claude writes it, giving the most logical reasons for the choice, whether Claude or you made it. Edit it freely if your real reasons differ.

## Template

```md
# {Decision title}

## What was considered
{Options, with a link to the decision file}

## Why this was chosen
{The most logical reasons}

## Costs accepted
{Downsides taken on knowingly}

## What would change this
{Conditions under which the other option wins}
```

Open decisions get a placeholder here until they are decided.
