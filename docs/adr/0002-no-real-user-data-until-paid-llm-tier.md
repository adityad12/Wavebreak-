# No real user data until the LLM runs on a paid, no-training tier

Conversations with the Companion contain highly sensitive information about relapses and health. Google's unpaid Gemini API tier may use prompts and responses to improve its products, and there is no budget for the paid tier. So v1 is a private demo used only with made-up conversations; real users arrive only once the project can pay for a tier whose terms exclude training on user data. The LLM sits behind a provider adapter so it can be swapped.

## Consequences

- No public launch, and no conversation sharing for improvement, until this changes.
- The "share this conversation to help others" opt-in is designed but not built.
- Check Google's current terms before the switch, since the sources found were mostly third-party.
