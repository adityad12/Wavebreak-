# AGPL-3.0 licence, with the author holding sole copyright

The project is open source because existing recovery tools are paid, but the author may want a paid hosted version if it gains traction. We chose AGPL-3.0, which keeps the code free and stops a competitor running a closed fork as a service. To keep the right to relicense or sell a hosted version, the author stays sole copyright holder and accepts no outside contributions until the paid-plan decision is made.

## Considered Options

- **MIT**: maximum freedom, but anyone could take the code and close it, which defeats the reason for open-sourcing it.
- **AGPL-3.0 with a contributor licence agreement**: allows contributions, but adds legal overhead too early.
