# Wavebreak

A free, open-source website (app later) that helps people stop a compulsive behaviour, with an AI companion to talk to when an urge hits.

## Language

**Behaviour**:
The specific habit a user is trying to stop. v1 covers nicotine, social media and porn.
_Avoid_: Addiction (as a label for the user's tracked item), substance

**Urge**:
The moment a user feels pulled back toward the Behaviour and reaches for the Companion. It is not tracked or counted.
_Avoid_: Craving, temptation, trigger (a trigger causes an urge; it is not the urge)

**Lapse**:
A single occasion of returning to the Behaviour, logged as an event rather than a failure.
_Avoid_: Slip-up, fail, fall

**Relapse**:
A return to the full old pattern of the Behaviour, as opposed to a single Lapse. The user decides when it has happened; the app never declares it.
_Avoid_: Failure, falling off the wagon

**Streak**:
The number of days since the user's last Lapse. The user also sees their **Best Streak**, the longest previous one, as the target to beat.
_Avoid_: Days clean (implies the user is "dirty" otherwise)

**Milestone**:
A fixed Streak length (1, 3, 7, 14, 30, 60 and 90 days) at which the user is congratulated.
_Avoid_: Achievement, badge

**Goal**:
The single Streak length the user chooses as their target for a Behaviour, at which the user is congratulated and chooses to keep tracking or mark the Behaviour **Completed**, which keeps its history and can be restarted. A Goal is a personal target, never a claim that the addiction has ended.
_Avoid_: Cure, target

**Activity**:
Something the user likes doing, picked from a starter catalogue of hobbies and offered as a distraction during an Urge. Suggestions the user rejects are replaced with new ones.
_Avoid_: Hobby, distraction (as a noun for the list item)

**Quote**:
A pre-vetted, public-domain or licensed line of encouragement, chosen to fit the user's situation (new Streak, Urge, after a Lapse, milestone). Never generated by the AI.
_Avoid_: Affirmation, motivation

**Companion**:
The AI chat the user talks to during an Urge.
_Avoid_: Bot, therapist, coach

**Crisis**:
A moment where the user shows signs of self-harm, withdrawal danger or overdose risk, after which the Companion stops coaching, shows a fixed caring message with helplines, and stays available if the user writes again.
_Avoid_: Emergency, red flag
