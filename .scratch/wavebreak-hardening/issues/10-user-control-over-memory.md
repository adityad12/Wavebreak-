# Let the user edit or clear what the Companion remembers

Status: needs-triage

Raised by Claude, 2026-11-04.

## Problem
The page shows "What I remember from earlier in this chat", but the user can't correct a wrong note or remove one. A summary can be wrong or include something the person doesn't want kept.

## Why it matters
Visible memory builds trust only if it is controllable. A wrong note about someone's triggers or safety can also steer later replies.

## Done when
- The user can delete a note and clear the whole memory, and edits take effect on the next message.
- Browser tests cover it (see ticket 05).
